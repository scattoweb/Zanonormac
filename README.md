# Сайт Zanon & Ormac

Новый сайт дилера спецтехники Zanon & Ormac (zanormac.net): склад новой и б/у техники, аренда, сервис, запчасти. Языки: итальянский, немецкий, английский.

Сделан на [Astro](https://astro.build): на выходе получается статический сайт (папка `dist/`) без базы данных и сервера. Его можно разместить на любом хостинге.

## Запуск

Нужен Node.js 20 или новее.

```bash
npm install
npm run dev      # http://localhost:4321 — разработка с автообновлением
npm run build    # готовый сайт в dist/
npm run preview  # посмотреть собранный сайт
npm run check    # проверка типов
```

## Страницы

Каждая страница есть на трёх языках: `/it/…`, `/de/…`, `/en/…`. Корень `/` отправляет посетителя на язык браузера.

| Путь | Что там |
|---|---|
| `/{lang}/` | Главная: поиск по наличию, склад, бренды, быстрая заявка на аренду, мастерские, контакты |
| `/{lang}/macchine/` | Каталог с фильтрами. Фильтры сохраняются в адресе, поэтому ссылкой на подборку можно поделиться |
| `/{lang}/macchine/{slug}/` | Страница машины: галерея, характеристики, лизинговый калькулятор, WhatsApp с готовым текстом |
| `/{lang}/noleggio/` | Аренда: парк, тарифы за день, неделю или месяц, расчёт стоимости, заявка |
| `/{lang}/privacy/` | Политика конфиденциальности |

## Как обновлять данные

Тексты и данные лежат в `src/`:

- `src/data/inventory.ts` — **склад**. Одна машина = один блок: модель, год, моточасы, цена (`null` = «цена по запросу»), статус (`ready` — в наличии, `incoming` — едет, `reserved` — забронирована), филиал, фото. Чтобы добавить машину, положите фото в `src/assets/img/`, импортируйте его вверху файла и скопируйте любой блок.
- `src/data/rental.ts` — **парк аренды**: цена за день, скидки за неделю и месяц (`WEEK_FACTOR`, `MONTH_FACTOR`), доп. оборудование, вопросы и ответы.
- `src/data/company.ts` — реквизиты, телефоны филиалов. Здесь же отмечено, какие филиалы включают немецкий язык (`de: true`).
- `src/data/brands.ts` — блок брендов на главной.
- `src/i18n/ui.ts` — все тексты интерфейса на трёх языках.

> **Важно:** годы, моточасы, цены, вес, мощность и тарифы аренды сейчас **примерные**, их нужно заменить реальными. Фото, телефоны, адреса и имена менеджеров взяты с текущего сайта zanormac.net.

## Заявки с сайта

Формы (контакты, аренда, запчасти, «сообщите о новых машинах») работают двумя способами:

1. Если задана переменная `PUBLIC_FORM_ENDPOINT` (см. `.env.example`), заявка уходит туда POST-запросом в формате JSON. Подойдёт Formspree, Web3Forms или свой обработчик.
2. Если переменная не задана, открывается WhatsApp `+39 348 745 4575` с уже написанным сообщением. Так сайт работает сразу, без внешних сервисов.

## Филиал и язык

Посетитель выбирает «свой» филиал: в верхней полосе, в списке мастерских, в форме аренды или в фильтре каталога. От филиала зависят телефоны на странице. Если выбрать Больцано или Fornace (Тренто), сайт переходит на немецкий. Появляется уведомление с кнопкой «Rückgängig», которая отменяет переход. Если потом выбрать филиал в Ломбардии, язык возвращается на итальянский, но только если немецкий включился автоматически. Если посетитель сам выбрал язык переключателем IT / DE / EN, сайт его не меняет.

## Публикация

После `npm run build` содержимое `dist/` загружается на любой хостинг статических сайтов: Netlify, Vercel, Cloudflare Pages, GitHub Pages или обычный хостинг с FTP. Адрес сайта для карты сайта и ссылок задаётся в `astro.config.mjs` (`site`).

## Что сделано для скорости, SEO и конфиденциальности

- Фото автоматически сжимаются в WebP нескольких размеров.
- Шрифты хранятся на самом сайте, без Google Fonts: это быстрее и не передаёт данные посетителей третьим лицам.
- Нет cookie для отслеживания и нет аналитики, поэтому баннер про cookie не нужен. В браузере сохраняются только выбранный филиал, язык и избранное.
- Есть `sitemap-index.xml`, ссылки `hreflang` между языками и разметка schema.org (компания и машины).
- Если в системе посетителя отключены анимации, сайт их тоже отключает.
